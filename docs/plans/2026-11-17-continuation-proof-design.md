# 跨栏 / 跨页续接校对

在0.5.10基线上处理剩余9处，优先断词和SQL点号。不降低0.90阈值，不覆盖人工编辑或以局部高分替代整段核验。

续接只考虑阅读顺序相邻、栏/页边界的普通正文，排除代码、表格、图示、标题和图注。词首/词尾必须组成当前文档出现过且没有连字符冲突的词。独立识别两端原图行，再识别不改像素的上下拼接图；核验合词候选与保留连字符候选，前者需达到阈值且至少领先0.05。任一步不一致保持原文。

不直接改原始OCR。校对预览、复制与导出共用documentProof双端覆盖层；双方原文/key匹配、无人工编辑或复核时才同时应用。取消不提交新记录；每次模型调用前后检查取消。局部断词修正不清除原有整段待复核。JSON记录候选、识别和分数。

SQL 整块和不足 100 像素的短正文沿用小块的固定等比例缩放及白边；普通长段保留原图，不择高。SQL字面渲染、字符串/注释保护及逐行完整性要求不变，保存whole审计和未采用的标点候选。

回归：跨页几何、词汇冲突、弱分数/分歧、双端修订失效、人工修改、成对导出、重复应用、取消后不发送下一次模型请求。实测同一份7页纯扫描版，并对照上一版最终文本检查增删；原PDF只用于导出后独立对照。
