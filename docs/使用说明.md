# PaperLens 使用说明

完整安装、操作、限制和构建方法见仓库根目录 [README](../README.md)。

日常流程：导入 → 识别全部页面 → 查看待复核 → 对照原图编辑并人工确认 → 导出校对版。

- OCR 未启动：进入模型设置，先启动引擎。
- 识别中取消：已完成文字保留，使用「继续识别未完成内容」恢复。
- 校对版不可导出：完成剩余页面，或切换「原始 OCR」导出当前已有文字。
- 人工确认点错：点击「撤销上一次复核」，会返回原段落，保留已修改的文字。
- 修改 CPU 模式或模型路径：先停止 OCR，再保存配置、重新启动。
- 完整性检查：不要只看 Jev 分数；对照每页原图检查标题、图注、表格、代码及页边缘文字。
