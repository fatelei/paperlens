# 扫描细节校对与 CI

目标：扫描识别后自动检查 SQL 标点、英文断词和图表标签/刻度，不依赖特定文档答案；人工修改始终优先。用同一份七页扫描版独立重跑并报告剩余待复核。

设计：保留原 OCR；从当前文档已识别文字建立断词候选证据（只建议，不盲改）。对代码、图表和疑似断词进行细节复读；按像素空白行、连通组件分出文本小块，再由 MiniCPM-OCR 识别和 Jev 核验。细节有冲突或失败时不得用高整段分数掩盖，保留待复核。候选和分数绑定文字修订，取消和人工编辑阻止迟到结果。已有人工确认不自动重写。

验证：合成像素/候选回归覆盖零字符、SQL 点号与下划线、真实连字符保留、数值不猜补、迟到结果和人工保护。真实七页扫描不接入文字层、不使用上次人工答案。保留自动结果供对照。

CI：push/PR 手动运行测试，最小只读权限；macOS 与 Windows 构建上传产物，不上传模型、用户文件或配置。不自动签署发行版或发布 release。
