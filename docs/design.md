# PaperLens 0.5.7 架构

Go/Wails 管理设置、文件选择、导出与本地模型生命周期。OCR 使用 MiniCPM-OCR 1.0 llama-server；核验使用独立 MiniCPM-OCR-Jev llama-server 和官方 Python 渲染评分 SDK。前端使用静态 JavaScript 和 PDF.js，文档与编辑结果保存于 WebView IndexedDB。

## 文档处理

DocLayout-YOLO 自动检测栏、段落、表格和公式，并进行分块补漏检测。自动段落保存坐标和识别原文，全文按阅读顺序合并。每段识别后运行 Jev；扫描件低分区域经过有限次重识别、增强或横向分块后再次核验。候选达到阈值且满足改善条件才进入独立校对版。含可见文字层的 PDF 以文字层坐标提供另一种校对依据。

人工文字和复核优先。异步核验、校对候选与单段识别结果检查文字修订号，避免过期结果覆盖新编辑。继续识别保留已有分区、人工修改和已确认内容。显式整页重新识别需要确认覆盖。

导入独立于推理任务；模型请求仍串行。任务状态包含识别、核验、校对、取消与部分失败。导出必须有文本，校对版要求各页已形成校对结果；待复核内容会保留警示，不伪装为全部正确。

## 本地运行边界

两个推理服务仅监听回环地址。应用使用随机临时会话令牌，持久设置不含令牌。核验候选在本机 Chromium 渲染，阻止 HTTP/HTTPS 外部访问。应用退出时终止自身启动的进程组。

区域评分、Q8_0 量化、渲染字体和版面检测均有局限，分数不是逐字准确率。自动化测试覆盖状态和故障恢复；真实扫描件仍需逐页对照遗漏与错字。
